# Shared adventure

Mode: Operate. Extend Together using the approved prototype's two illustrated
alternatives and one accepted adventure. Inherit the notebook Material 3 system,
evergreen controls and bundled dojo artwork. No new visual identity.

The first view shows two alternatives with task counts and an explicit preview.
Preview names the actual tasks before the family-wide start. The accepted view
shows artwork, title, distinct-root progress and current task/checklist text.
Editing changes phase names, advisory estimates and root references, never task
content. Leaving requires a shared-consequence confirmation. Completion stays
visible until dismissed; a short Bun bow is acknowledged durably before motion.

Keep all content scrollable with 48 dp controls, readable Finnish and English,
and wrapped large text. Preserve cached work on connection failure and distinguish
unavailable source tasks. Artwork always has a bundled fallback. The queue remains
the place for ordinary task actions and Undo. The guided creator asks for an outcome and optional minutes, then separates
existing references from editable new tasks. Explicit approval reserves the
shared start; pending sync remains visible and recoverable without claiming
success. The integrated signpost extends this flow in its own slice.
