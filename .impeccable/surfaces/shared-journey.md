# Shared Bun journey

Mode: Operate. Extend Together with the existing evergreen, warm-paper and native
Material language. The Bun world contract settles the shared journey and its
optional nature. The full world scene, adventures and artwork catalog are separate
parts of that contract, not placeholders on this screen.

Open without changing family state. An explicit online start explains that new
first completions move Bun, while previous completions stay in statistics. Reuse
the approved dojo artwork and rabbit mark. Show the current stop, an ordered route
and plain-text accepted progress. Keep completed paths in history. No countdown,
rankings, XP, auto-start or new motion.

Use the existing type ramp, 24 dp content gutters and 48 dp minimum controls. All
content scrolls, including artwork, so starting, refreshing and leaving remain
reachable at large text and short heights. The world-off setting and existing
short-screen/large-text rules hide decoration. Finnish and English describe the
same states. Keep cached progress on connection failure, show when it was updated,
and never present optimistic task edits as accepted journey progress.
